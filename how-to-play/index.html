Start with the seven daily prompts

Open the official game at krillion.io and read its on-screen instructions. The daily reveal recorded here contains seven prompts. Each prompt sets its own conditions: a word ending, a category, a date or an exclusion can change whether your idea fits. Check the game date before using a past answer.

Play the official Krillion game ↗

Choose a hint before revealing an answer

Start by checking the full question. Our first-letter and word-shape clues describe one recorded example, not every answer the question accepts. If that is enough to spark an idea, return to the game. Otherwise open an example or the searchable answer list.

See the latest Krillion hints ↗

Understand answer rarity and points

The recorded answer sets contain six tiers, from Plankton at 10 points to One in a Krillion at 100. A score belongs to an answer in a specific prompt. The official FAQ explains that the special Krillion pick also considers how satisfying an answer is, rather than rarity alone.

Read the rarity and scoring guide ↗

Check the date and original source

Only a complete, validated seven-prompt record enters this archive. The page keeps the actual game date if a newer reveal cannot be saved. A missing result in our search is not a verdict that the live game rejects an answer; later corrections can differ from a saved snapshot.
